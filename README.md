# 🚗 Self-Driving Car Simulation

 A **Self-Driving Car Simulation** developed using **JavaScript, HTML, and CSS**. The project demonstrates the basic concepts of autonomous driving by using virtual sensors, collision detection, and a neural network to help the car make driving decisions and navigate the road.

 ## 🎯 Objective

 The objective of this project is to simulate an autonomous vehicle that can detect its surroundings, avoid obstacles, and make driving decisions using sensor data and a neural network.

 ## ✨ Features

 - 🚘 Self-driving car simulation
- 📡 Virtual sensors for obstacle detection
- 🧠 Neural network-based decision making
- 🛣️ Road and traffic simulation
- 💥 Collision detection
- 🎨 Real-time visualization
- ⌨️ Manual car controls

 ## 🛠️ Technologies Used

 **JavaScript | HTML5 | CSS3 | Canvas**

 ## 📌 Project Description

 This project provides a simple and interactive demonstration of how autonomous driving systems can use **sensors and neural networks** to understand the environment and control a vehicle.
