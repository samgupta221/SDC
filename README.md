# 🚗 SELF-DRIVING-CAR

A browser-based **Self-Driving Car Simulation** built using **JavaScript, HTML5, CSS3, and Canvas**.

This project demonstrates the basic concepts behind autonomous driving by combining road generation, vehicle movement, sensors, collision detection, and neural-network-based decision making into an interactive visual simulation.

---

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| **JavaScript** | Core application and simulation logic |
| **HTML5** | Application structure |
| **CSS3** | Styling and user interface |
| **Canvas API** | Rendering the simulation |
| **Neural Network** | Autonomous decision making |
| **Git & GitHub** | Version control |
